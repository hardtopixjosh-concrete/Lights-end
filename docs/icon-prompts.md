# VEYRATH spell icon prompts

Paste the **Style block** first, then ask for icons one at a time (or a few per message) from the lists below. Each line gives the file name to save as and what the icon should show.

---

## Style block (paste this first)

> I'm making ability icons for VEYRATH, a top-down dark-fantasy action roguelite set in a sun-scorched desert (sandstone ruins, pyramids, oases, demons). Make every icon in this exact shared style so they look like one set:
>
> - Square 1:1 image, 512×512, one icon per image.
> - Hand-painted digital fantasy game ability icon, like a premium ARPG skill icon (Diablo / Path of Exile / Last Epoch style). It should not look like pixel art, flat vector art, a photo, or a 3D render.
> - One bold central subject that reads clearly at 48 px. Strong silhouette, high contrast, minimal background clutter.
> - Dark, near-black background with a soft glow in the spell's colour behind the subject. No frame, border, text, letters, numbers or UI.
> - Dramatic lighting from the spell's own energy. Rich, saturated main colour plus a darker shade and a bright hot core.
> - The subject fills about 80% of the canvas and is centred, with a small margin so a round or square frame can go on top later.
> - Keep the brushwork, level of detail and lighting the same across the whole set.
>
> Each request I send gives the file name, colour and subject. Reply with the image only.
